## About the Project

Recipe Book is a simple Python program that displays recipes and their cooking instructions. Users can select a recipe, view its ingredients, and add it to a cooking queue.

## Features

- View the list of available recipes.
- View recipe ingredients and instructions.
- Add recipes to the cooking queue.
- View recipes in the queue.
- Prepare the next recipe in the queue.
- Handle invalid menu inputs.

## How to Run

1. Install Python 3.
2. Open Command Prompt or a terminal.
3. Go to the project folder.
4. Run the following command:

   ```bash
   python main.py
   ```

   On Windows, you can also use:

   ```bash
   py main.py
   ```

## Main Menu

1. View Recipe Menu
2. Select a Recipe
3. View Cooking Queue
4. Prepare Next Recipe
5. Exit

## Queue Operation

Recipes are added to the end of the queue. When the user chooses to prepare the next recipe, the first recipe is removed and displayed. This follows the First In, First Out (FIFO) principle.

## Project Objective

The objective of this project is to practise basic Python programming by creating a simple recipe manager with recipe details and cooking queue operations.
